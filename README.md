# Hand Gesture Volume Control

## Overview

This project allows users to control their system volume using hand gestures captured through a webcam.

Using computer vision and hand tracking, the distance between the thumb and index finger is converted into volume levels in real time.

## Features

- Real-time hand detection
- Gesture-based volume control
- Webcam integration
- Smooth volume adjustment
- Visual feedback on screen

## Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy
- Pycaw

## How It Works

1. Webcam captures hand movements.
2. MediaPipe detects hand landmarks.
3. Distance between thumb and index finger is calculated.
4. Distance is mapped to system volume.
5. Volume changes dynamically based on finger movement.
